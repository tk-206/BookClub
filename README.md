## 트러블 슈팅

### 좋아요 갱신 시 UI가 변경되지 않는 문제

문제

* 게시글 좋아요는 정상적으로 저장되었지만 모달의 좋아요 수가 변경되지 않았다.

원인

* selectedPost를 별도의 state로 관리하고 있었기 때문에 React Query 캐시가 갱신되어도 모달 데이터는 변경되지 않았다.

해결

* 게시글 객체 전체를 저장하는 대신 게시글 id를 관리하도록 변경하였다.
* React Query 캐시를 단일 데이터 소스로 사용하도록 구조를 수정하였다.
